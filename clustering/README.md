# Clustering

K-means and Hierarchical Agglomerative Clustering (HAC) applied to the Abalone, Iris, and white wine quality datasets. Covers initial-centroid sensitivity in K-means (manual runs vs. `n_init` vs. K-means++), silhouette-based evaluation across cluster counts, comparison of HAC linkage methods (single, average, complete, ward), and applying both algorithms to an unfamiliar dataset.
